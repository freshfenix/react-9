# Форма реєстрації на React

Навчальний проєкт із вебформою, створеною за допомогою React, Formik та Yup. Інтерфейс і повідомлення про помилки українською мовою.

## Запуск проєкту

Потрібен Node.js та npm.

```bash
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite у терміналі (зазвичай `http://localhost:5173`).

## Поля та валідація

Форма в [src/components/Form.jsx](./src/components/Form.jsx) містить чотири обов'язкові поля:

- **Ім'я** — після видалення пробілів має містити щонайменше два символи.
- **Електронна пошта** — має бути заповнена та мати коректний формат.
- **Пароль** — щонайменше вісім символів, серед яких є літера та цифра.
- **Підтвердження пароля** — має збігатися з паролем.

Formik керує значеннями та станом форми, а схема Yup перевіряє введені дані. Помилка показується під відповідним полем після взаємодії з ним або спроби надіслати форму. Після валідного надсилання форма очищується, а на екрані з'являється повідомлення про успішну перевірку.

Надсилання реалізоване локально для демонстрації: дані не передаються на сервер і не зберігаються. Пароль не відображається у повідомленні про успіх.
